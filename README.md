# Curso de Git

Repositório criado para praticar os primeiros passos com **Git** e **GitHub**.

## Comandos básicos

```bash
git init                 # cria um repositório
git add .                # prepara os arquivos para o commit
git commit -m "mensagem" # salva uma versão
git remote add origin <url>
git push -u origin main  # envia para o GitHub
```
